# Changelog

## v2.0 (2026-05-11) — Decision OS

Complete rewrite to a universal, practical decision tool.

### Added
- `index.html` — Interactive web app (open in browser, works offline)
- GitHub Pages deployment support
- Branch simulation with best/likely/worst outcomes
- Alternate self review generation
- History tracking (localStorage)
- Markdown export
- Dark/light theme

### Changed
- Project renamed from `self-evolution-agent` to `decision-os`
- Removed all OpenClaw dependencies
- Platform-agnostic: works with any browser or any AI
- Bilingual README (English-first, global audience)
- Templates simplified and made standalone

## v1.0 (2026-05-11) — Original

OpenClaw-specific skill for decision simulation and alternate self review.
